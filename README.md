# Java Project Matching App

Javaの自己学習で習得した内容を使って開発している、案件マッチングアプリです。

案件情報とエンジニアのスキル・希望条件を比較し、案件とのマッチ度を確認できるアプリを目指しています。

## 現在のバージョン

**Ver0.1 - Javaコンソール版**

現在はJava基礎の理解を深めることを目的に、コンソール上で動作するアプリを開発しています。

## 実装済み

- メインメニュー
- 案件一覧表示
- 必須スキルによる案件検索

## 実装予定

- リモート可能案件の表示
- マッチスコア計算・表示

## 使用しているJavaの内容

- 変数
- データ型
- 配列
- if文
- switch文
- while文
- for文
- Scanner
